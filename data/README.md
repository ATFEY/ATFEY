# Folder Data

Folder ini berisi berkas data mentah sekunder yang digunakan dalam analisis klasterisasi K-Means.

## Berkas
- **`FSVA_Data_Nasional_2025.xlsx`**: Data Peta Ketahanan dan Kerentanan Pangan (Food Security and Vulnerability Atlas - FSVA) tahun 2025 tingkat kabupaten/kota di Indonesia.

## Sumber Data
Data dipublikasikan secara resmi oleh **Badan Pangan Nasional (Bapanas) / Kementerian Pertanian Republik Indonesia**.
